`fe7300ebf665c42d965bc8550775193eaf73e10c` to a reproducible regression test
and the smallest safe implementation change. It was written before changing
the implementation.

## H6 CI gate

H6 is handled as a delivery gate rather than a runtime change. After the
remediation commit is pushed to the existing branch, checks and workflow runs
must be queried for that exact SHA. A missing or disabled workflow is reported
as not run, never as passed. No workflow or quality gate will be weakened to
manufacture a green result.

## API constraints used by the repair

- The installed Notion SDK exposes `fileUploads.list()` for uploads owned by
  the current bot connection.
- An uploaded File Upload must be attached before its expiry; after attachment
  its expiry is cleared and the ID remains reusable, including after deleting
  the original block.
- A Block response exposes its parent, block type, creator, and trash status.
- A 404 does not provide enough evidence to distinguish absence from content
  hidden by connection permissions, so it is never positive deletion proof.
